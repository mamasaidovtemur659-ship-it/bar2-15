## Быстрый запуск

Просто откройте `index.html` в браузере — приложение работает без сервера.

## Развёртывание

### Vercel (рекомендуется — бесплатно)
1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Установите CLI: `npm i -g vercel`
3. В папке проекта выполните: `vercel`
4. Введите email и подтвердите — ссылка будет готова за 30 секунд

### Netlify (альтернатива)
1. Зайдите на [netlify.com](https://netlify.com)
2. Перетащите папку `bar215-app` в браузер на страницу Netlify Drop
3. Готово — получите ссылку вида `https://xxxxx.netlify.app`

### GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите файлы
3. Settings → Pages → Source: main branch

### Локально
```bash
npx serve . -p 3000
# Откройте http://localhost:3000
```

## Функционал

- ☀️ **Завтраки** — список гостей, отметка явки, история 7 дней, сортировка, точки присутствия
- 🕐 **Обеды** — ввод гостей и сотрудников, история
- 📖 **Меню** — 44 блюда (загружены с фото вашего меню), добавление/редактирование
- 👤 **Смены** — официанты, повара, посудомойки/уборщицы, ФОТ по месяцам, статистика по сотрудникам
- 📊 **Финансы** — доходы, расходы, ФОТ, прибыль, диаграммы, помесячный отчёт
- ⚡ **AI Сканер** — Tesseract OCR + GigaChat нейросеть

## AI Сканер

**Без ключа:** Tesseract OCR (работает офлайн).

**С GigaChat токеном:** нейросеть анализирует текст точнее.
Получить токен: [developers.sber.ru](https://developers.sber.ru) → GigaChat API.
